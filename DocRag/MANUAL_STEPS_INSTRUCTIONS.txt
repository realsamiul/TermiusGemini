   --> Click "Email/Password" and click Enable. Save changes.

   --> Click "Generate key" and save the downloaded JSON file to your local machine.

--------------------------------------------------------------------------------
STEP B: PLACE THE PRIVATE KEY JSON ON THE VM (~2 minutes)
--------------------------------------------------------------------------------
Copy the text inside your downloaded Firebase credentials JSON file and save it 
to the VM at: ~/docrag-legal/secrets/firebase-key.json

Run this command in Termius:
cat > ~/docrag-legal/secrets/firebase-key.json << 'EOF'
<PASTE YOUR COPIED FIREBASE KEY JSON TEXT HERE>
EOF

--------------------------------------------------------------------------------
STEP C: SET CUSTOM USER ADMIN CLAIMS (~2 minutes)
--------------------------------------------------------------------------------
Execute this Python one-liner in Termius to tag your user as an admin in Firebase.
Make sure to replace "PASTE_YOUR_TEST_USER_UID_HERE" with the UID from Step A.4:

/home/realsamkarim/.venv/bin/python - <<'EOF'
import firebase_admin
from firebase_admin import credentials, auth
import json

cred_path = "/home/realsamkarim/docrag-legal/secrets/firebase-key.json"
cred = credentials.Certificate(cred_path)
firebase_admin.initialize_app(cred)

# REPLACE with the User UID from your Firebase console
uid = "PASTE_YOUR_TEST_USER_UID_HERE" 

auth.set_custom_user_claims(uid, {"role": "admin"})
print(f"Successfully set admin role for Firebase User: {uid}")
EOF

--------------------------------------------------------------------------------
STEP D: SECURE FIREBASE CREDENTIALS IN SECRET MANAGER (~2 minutes)
--------------------------------------------------------------------------------
Execute this command on your VM to upload the key securely into Google Secret Manager:

gcloud secrets create firebase-creds \
  --data-file=/home/realsamkarim/docrag-legal/secrets/firebase-key.json \
  --project="project-a1f62154-a7ad-4b37-93b"
